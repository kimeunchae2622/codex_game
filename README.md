# 잊힌 종의 정원

한국어 오리지널 웹 메트로배니아 액션 게임입니다.

## 조작법

- 방향키: 이동 / 올려보기 / 숙이기
- Z: 점프
- X: 공격 (`↑` 또는 `↓`를 함께 누르면 해당 방향 공격, 아래 공격 적중 시 살짝 도약)
- C: 대시
- A: 상점 나가기
- Esc: 일시정지

모험 구간에는 좌우·상하로 움직이는 빛 발판과, 밟으면 잠시 후 무너졌다가 복구되는 갈라진 발판이 등장합니다.

메아리 수집 상태와 탐색도, 체크포인트는 브라우저에 자동 저장됩니다.

정원은 지상뿐 아니라 위쪽 `빛의 수관`과 아래쪽 `가라앉은 뿌리`로 이어집니다. 별 없는 온실의 발판을 따라 수관으로 올라가거나, 지상 틈의 승강 발판을 타고 지하 뿌리 구역을 왕복할 수 있습니다.

빛의 수관 끝에는 정원 밖의 신규 지역 `달빛 시계탑`이 이어집니다. 톱니 탄환을 발사하는 `태엽눈`과 지역 보스 `월륜의 파수꾼`이 등장하며, 보스를 쓰러뜨리면 대시 재사용 시간이 줄어드는 `월륜 톱니`를 얻습니다.

가라앉은 뿌리 끝에는 정원 아래의 신규 지역 `침수된 기록고`가 이어집니다. 빠르게 돌진하는 `먹물령`과 지역 보스 `먹빛 사서`가 등장하며, 보스를 쓰러뜨리면 코인을 더 먼 거리에서 끌어오는 `회수의 인장`을 얻습니다.

몬스터를 처치하면 코인이 떨어지며, 처치된 몬스터는 저장되어 다시 등장하지 않습니다. 뿌리 상인 앞에서 `↓`를 누르면 상점이 열립니다. 상점에서는 방향키로 품목을 고르고 `Z`로 구매하며 `A`로 나갑니다. 모든 메아리를 모으고 장비를 갖춘 뒤 중간 보스 `청록 수문장`까지 쓰러뜨려야 `종루의 열쇠`를 살 수 있습니다.

사망하면 보유 코인이 사망 지점 근처의 안전한 바닥에 떨어집니다. 회수 전에 다시 죽으면 기존 코인 더미는 사라지고, 두 번째 사망 당시 소지한 코인만 새로 떨어집니다.

최종 보스 `심연의 종지기`는 돌진, 강하 충격파, 조준 탄막을 사용하며 체력이 절반 이하가 되면 공격 속도와 탄막 수가 증가합니다.

플레이어 체력은 기본 4칸이며 이끼 갑옷을 구매하면 최대 5칸입니다.

시작 화면의 `처음부터 새 게임` 또는 일시정지 화면의 `진행 상황 초기화`를 누르면 확인 후 모든 저장 데이터를 지우고 처음부터 다시 시작합니다.

`index.html`을 브라우저로 열거나 `npm install && npm run dev`로 실행할 수 있습니다.
