# 잊힌 종의 정원

한국어 오리지널 웹 메트로배니아 액션 게임입니다.

## 조작법

- 방향키: 이동 / 올려보기 / 숙이기
- Z: 점프
- X: 공격 (`↑` 또는 `↓`를 함께 누르면 해당 방향 공격)
- C: 대시
- A: 상점 나가기
- Esc: 일시정지

모험 구간에는 좌우·상하로 움직이는 빛 발판과, 밟으면 잠시 후 무너졌다가 복구되는 갈라진 발판이 등장합니다.

대시 능력을 얻은 뒤 이전 지역의 보랏빛 `뿌리 기억 봉인`을 다시 찾아 깨면 최대 체력이 성장합니다. 메아리와 기억 수집 상태, 탐색도, 체크포인트는 브라우저에 자동 저장됩니다.

몬스터를 처치하면 코인이 떨어집니다. 뿌리 상인 앞에서 `↓`를 누르면 상점이 열리며 무기, 방어구, 이단 점프 능력을 구매할 수 있습니다. 모든 메아리와 기억을 모으고 장비를 갖춰 `종루의 열쇠`를 사야 가장 깊은 종루의 보스에게 갈 수 있습니다.

사망하면 보유 코인이 사망 지점 근처의 안전한 바닥에 떨어집니다. 해당 장소로 돌아가 코인 더미에 닿으면 전액을 회수합니다.

시작 화면의 `처음부터 새 게임` 또는 일시정지 화면의 `진행 상황 초기화`를 누르면 확인 후 모든 저장 데이터를 지우고 처음부터 다시 시작합니다.

`index.html`을 브라우저로 열거나 `npm install && npm run dev`로 실행할 수 있습니다.
