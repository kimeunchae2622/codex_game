# 잊힌 종의 정원

한국어 오리지널 웹 메트로배니아 액션 게임입니다.

## 조작법

- 방향키: 이동 / 올려보기 / 숙이기
- Z: 점프
- X: 공격 (`↑` 또는 `↓`를 함께 누르면 해당 방향 공격)
- C: 대시
- A: 상점 나가기
- Esc: 일시정지

모험 구간에는 좌우·상하로 움직이는 빛 발판과, 밟으면 잠시 후 무너졌다가 복구되는 갈라진 발판이 등장합니다.

대시 능력을 얻은 뒤 이전 지역의 보랏빛 `뿌리 기억 봉인`을 다시 찾아 깨면 최대 체력이 성장합니다. 메아리와 기억 수집 상태, 탐색도, 체크포인트는 브라우저에 자동 저장됩니다.

몬스터를 처치하면 코인이 떨어지며, 처치된 몬스터는 저장되어 다시 등장하지 않습니다. 뿌리 상인 앞에서 `↓`를 누르면 상점이 열립니다. 상점에서는 방향키로 품목을 고르고 `Z`로 구매하며 `A`로 나갑니다. 모든 메아리와 기억을 모으고 장비를 갖춘 뒤 중간 보스 `청록 수문장`까지 쓰러뜨려야 `종루의 열쇠`를 살 수 있습니다.

사망하면 보유 코인이 사망 지점 근처의 안전한 바닥에 떨어집니다. 회수 전에 다시 죽으면 기존 코인 더미는 사라지고, 두 번째 사망 당시 소지한 코인만 새로 떨어집니다.

최종 보스 `심연의 종지기`는 돌진, 강하 충격파, 조준 탄막을 사용하며 체력이 절반 이하가 되면 공격 속도와 탄막 수가 증가합니다.

시작 화면의 `처음부터 새 게임` 또는 일시정지 화면의 `진행 상황 초기화`를 누르면 확인 후 모든 저장 데이터를 지우고 처음부터 다시 시작합니다.

`index.html`을 브라우저로 열거나 `npm install && npm run dev`로 실행할 수 있습니다.
