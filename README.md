# 짭로나이트

한국어 오리지널 웹 메트로배니아 액션 게임입니다.

8개 지역에는 각각 고유한 실시간 합성 BGM이 재생되며, 보스 전투에는 별도의 전투곡이 적용됩니다. 상단의 `음악·효과음` 버튼으로 전체 소리를 켜거나 끌 수 있습니다. `설정`에서는 BGM·효과음 음량을 따로 조절하고 화면 흔들림과 픽셀 화면 효과를 변경할 수 있으며 선택값은 브라우저에 저장됩니다.

## 조작법

- 방향키: 이동 / 올려보기 / 숙이기
- Z: 점프
- X: 공격 (`↑` 또는 `↓`를 함께 누르면 해당 방향 공격, 아래 공격 적중 시 살짝 도약)
- C: 대시
- I: 장비·능력·인장 인벤토리
- A: 상점 나가기
- Esc: 일시정지

모험 구간에는 좌우·상하로 움직이는 빛 발판과, 밟으면 잠시 후 무너졌다가 복구되는 갈라진 발판이 등장합니다. 필수 상승 동선은 이중 점프 없이 오를 수 있도록 발판 높이가 75~80px 이내로 배치됩니다.

메아리 수집 상태와 탐색도, 체크포인트는 브라우저에 자동 저장됩니다.

정원은 지상뿐 아니라 위쪽 `빛의 수관`과 아래쪽 `가라앉은 뿌리`로 이어집니다. 별 없는 온실의 발판을 따라 수관으로 올라가거나, 지상 틈의 승강 발판을 타고 지하 뿌리 구역을 왕복할 수 있습니다.

월드는 가로 12,400, 세로 4,250 단위 규모로 확장되어 총 181개의 고정 발판과 다양한 이동·붕괴 발판으로 구성됩니다. 8개 지역에는 대형 추가 구역, 체크포인트, 전용 적 무리와 중간 보스가 있으며, 지역마다 두 개씩 배치된 탐험 기록 16개를 조사하면 이야기와 코인을 얻습니다.

빛의 수관 끝에는 정원 밖의 신규 지역 `달빛 시계탑`이 이어집니다. 톱니 탄환을 발사하는 `태엽눈`과 지역 보스 `월륜의 파수꾼`이 등장하며, 보스를 쓰러뜨리면 인장 `월륜 톱니`와 인장 슬롯을 얻습니다.

가라앉은 뿌리 끝에는 정원 아래의 신규 지역 `침수된 기록고`가 이어집니다. 빠르게 돌진하는 `먹물령`과 지역 보스 `먹빛 사서`가 등장하며, 보스를 쓰러뜨리면 인장 `기록고의 왕관`과 인장 슬롯을 얻습니다.

침수된 기록고와 별잠 해안 사이의 개방형 승강 통로는 양방향으로 이용할 수 있습니다. 좁은 구간의 발판과 심층 리프트는 아래에서 통과한 뒤 위에 착지할 수 있습니다.

몬스터를 처치하면 코인이 떨어지며, 처치된 몬스터는 저장되어 다시 등장하지 않습니다. 정원·달빛 시계탑·침수된 기록고의 지역 상인 앞에서 `↓`를 누르면 상점이 열립니다. 상점에서는 방향키로 품목을 고르고 `Z`로 구매하며 `A`로 나갑니다. 방랑자의 상점은 처음에 4개 품목만 판매하고, 대시 발견과 메아리 수집, `청록 수문장` 처치에 따라 재고가 5단계로 늘어납니다. 모든 메아리를 모으고 장비를 갖춘 뒤 수문장까지 쓰러뜨리면 마지막으로 `종루의 열쇠`가 입고됩니다.

인장은 총 30종입니다. 처음에는 3칸을 사용할 수 있고, 세 지역 상점의 슬롯 확장과 핵심 진행 보스 보상으로 최대 8칸까지 늘어납니다. 모든 보스가 슬롯을 주지는 않으며, 나머지 보스는 전용 인장이나 새로운 이동 능력을 제공합니다. `I` 인벤토리에서 방향키로 인장을 고르고 `Z`로 장착하거나 해제합니다. 초반 정원 상점의 1칸짜리 `회수의 인장`을 장착하면 거리에 상관없이 떨어진 코인과 사망 시 잃은 코인을 되찾습니다.

모든 지역의 일반 몬스터는 플레이어가 가까이 오면 공격 준비 동작을 보인 뒤 돌진·급강하·탄환 공격 등 각 종류에 맞는 공격을 사용합니다.

정원의 `청록 수문장` 외에도 빛의 수관, 가라앉은 뿌리, 달빛 시계탑, 종루, 침수된 기록고, 잿빛 제련소, 별잠 해안에 각각 전용 중간 보스가 등장합니다. 중간 보스는 돌진·도약 충격파·조준 탄막을 조합해 공격하며 처치 상태와 보상은 자동 저장됩니다.

사망하면 보유 코인이 사망 지점 근처의 안전한 바닥에 떨어집니다. 회수 전에 다시 죽으면 기존 코인 더미는 사라지고, 두 번째 사망 당시 소지한 코인만 새로 떨어집니다.

종루 보스 `심연의 종지기`는 돌진, 강하 충격파, 조준 탄막을 사용하며 체력이 절반 이하가 되면 공격 속도와 탄막 수가 증가합니다. 종지기를 쓰러뜨리면 `종의 공명`을 얻고 종루 오른쪽의 공명문이 열립니다.

공명문 너머에는 신규 지역 `잿빛 제련소`와 `별잠 해안`이 이어집니다. 제련소의 지역 보스 `잿불 제련심장`을 쓰러뜨리면 용광로 내성을 얻어 해안으로 내려갈 수 있습니다. 별잠 해안의 왼쪽 통로는 침수된 기록고로 연결되어 정원 → 종루 → 제련소 → 해안 → 기록고 → 가라앉은 뿌리 → 정원으로 돌아오는 순환형 메트로배니아 동선을 완성합니다.

별잠 해안 끝에는 지역 보스 `별잠 포식자`가 기다립니다. 포식자를 쓰러뜨린 뒤에도 진행 상황을 유지한 채 모든 지역과 지름길을 계속 탐험할 수 있습니다.

플레이어 체력은 기본 4칸이며 이끼 갑옷과 장착한 인장에 따라 최대 체력이 늘어납니다.

시작 화면의 `처음부터 새 게임` 또는 일시정지 화면의 `진행 상황 초기화`를 누르면 확인 후 모든 저장 데이터를 지우고 처음부터 다시 시작합니다.

`index.html`을 브라우저로 열거나 `npm install && npm run dev`로 실행할 수 있습니다.
